# 🛒 E-Commerce Database Management System

This project implements a robust and scalable database system tailored for e-commerce platforms. Built using SQL Server, it handles essential modules such as customer data, product inventory, order tracking, payments, shipping, and returns/exchanges. Inspired by real-world platforms like Amazon and Flipkart, the system simulates the full order lifecycle using structured queries, stored procedures, and triggers.

## 📌 Key Features

- Designed and implemented a relational database system for an e-commerce platform using SQL Server.
- Managed core entities such as customers, products, orders, payments, sellers, shipping, cart, and returns.
- Created a detailed ER diagram and normalized relational schema to 3NF for scalable and efficient data storage.
- Developed comprehensive SQL queries for creating, inserting, retrieving, and updating data.
- Implemented advanced SQL triggers and stored procedures to automate order placement, product shipping, returns, and exchanges.
- Ensured referential integrity using foreign key constraints across all major tables.
- Enabled dynamic product tracking, return and exchange flows with real-time status updates.
- Incorporated feedback from interviews and surveys to reflect real-world e-commerce system requirements.
- Simulated end-to-end workflows such as order placement from cart, payment processing, and delivery updates.
- Achieved an optimized and well-documented database structure capable of supporting large-scale online retail operations.

## 🛠️ Technologies Used

- **Database:** SQL Server
- **Tools:** SQL Server Management Studio (SSMS)
- **Concepts:** ER Modeling, Database Normalization (up to 3NF), Stored Procedures, Triggers, Transactions

## 📂 Project Structure

- `ER Diagram.pdf` – Entity-Relationship model design
- `Schema.sql` – SQL scripts to create all tables
- `InsertData.sql` – Sample data insertion scripts
- `Queries.sql` – Queries to handle cart, orders, shipping, returns, and exchanges
- `StoredProcedures.sql` – All relevant stored procedures used in the workflow
